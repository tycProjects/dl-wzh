help How to Use / အသုံးပြုပုံ

၁။ Pack အသစ် ဖန်တီးပါ:
Create Pack tab တွင် "Create New Pack" ကိုနှိပ်ပြီး နာမည်ပေးပါ။
၂။ Skin (.png) မှ Head ထည့်ပါ:
"Add Head" နှိပ်ပြီး မိမိ Minecraft Skin ပုံကို ရွေးချယ်ကာ 3D Head ကို preview ကြည့်ပါ။

Downloads tab သို့သွားပြီး "Open" ကိုနှိပ်လိုက်သည်နှင့် Minecraft Bedrock ထဲသို့ တိုက်ရိုက် Import ဖြစ်သွားပါမည်။
