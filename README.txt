PRIVATE MEDIA CLEANER — ANDROID STUDIO PROJECT

IMPORTANT:
- This is a native Android Studio project, not an HTML file and not a WZH 2 APK Builder website-wrapper project.
- Open the folder in Android Studio, allow Gradle sync, then Build > Build APK(s).
- Requires Android Studio with JDK 17 and Android SDK Platform 35.
- Designed for Android 11+ bulk media deletion flow. Android shows its own system confirmation.
- The app requests deletion of photos/videos visible through MediaStore; it cannot promise to erase every file, app-private folder, cloud copy, or every SD-card item.
- The PIN is an in-app lock only, not a replacement for the device lock. Clearing app data removes the stored PIN.
- Test first with unimportant sample media. Never use without a backup.
