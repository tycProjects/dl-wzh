AnimeX - prototipe awal

AnimeX_Demo.html bisa dibuka di Chrome Android untuk mencoba antarmuka demo.

Folder proyek Android ini adalah KODE SUMBER, bukan APK yang sudah dikompilasi.
Untuk membuat APK, buka proyek dengan Android Studio versi terbaru, tunggu Gradle sync, lalu pilih Build > Build APK(s).

Batasan demo:
- Belum ada pembayaran Premium sungguhan atau verifikasi GoPay.
- Tombol Like menyimpan daftar sementara selama halaman aktif; belum menyimpan file secara persisten untuk offline.
- Unduhan URL hanya bekerja pada tautan file langsung jika server mengizinkan; beberapa sumber memblokir unduhan/CORS.
- Ekspor editing video, trending online, akun pengguna, dan unduhan otomatis Premium perlu pengembangan lebih lanjut.
- Untuk APK produksi, perlu integrasi Android download manager/media storage dan kebijakan hak cipta.
