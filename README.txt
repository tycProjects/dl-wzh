Плеер для Android (APK) с управлением из шторки уведомлений и с экрана блокировки

Как собрать APK:
1. Установите Android Studio (developer.android.com/studio).
2. File -> Open -> выберите эту папку (MusicPlayer). Дождитесь Gradle Sync.
3. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
4. Готовый файл: app/build/outputs/apk/debug/app-debug.apk. Скопируйте на телефон и установите.
5. При первом запуске разрешите уведомления (Android 13+).

Страница плеера лежит в app/src/main/assets/index.html. Чтобы обновить плеер, замените этот файл и пересоберите.
Если музыка останавливается при блокировке: Настройки -> Приложения -> Плеер -> Батарея -> Без ограничений.

Как поставить свою иконку и название:
- Название: откройте app/src/main/res/values/strings.xml и замените слово «Плеер» в строке app_name.
- Иконка: замените файл app/src/main/res/mipmap-xxxhdpi/ic_launcher.png своей картинкой (PNG, квадрат, лучше 512x512 или 192x192), имя файла оставьте ic_launcher.png.

Добавление треков в приложении: кнопка «+» открывает меню «Выбрать треки» (можно отметить много файлов) и «Выбрать папку целиком» (добавятся все треки из папки).
Порядок треков в плейлисте меняется перетаскиванием пальцем за значок «≡» справа.

Виджет на главный экран: в приложении откройте Настройки (шестерёнка) -> «Добавить виджет на главный экран». Если телефон не показывает запрос, добавьте вручную: долгое нажатие на пустом месте главного экрана -> Виджеты -> Плеер.
