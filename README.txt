الكرة الطايرة - مشروع أندرويد (APK)

المطلوب على الكمبيوتر:
1) تحميل Android Studio من developer.android.com/studio (مجاني).
2) من Android Studio: File > Open، واختار فولدر androidapp.
3) استنى Gradle Sync يخلص (أول مرة ممكن ياخد دقايق).
4) Build > Build Bundle(s) / APK(s) > Build APK(s).
5) هيطلع لك ملف APK في: app/build/outputs/apk/debug/app-debug.apk
6) انقله للموبايل وثبّته (لازم تفعّل "تثبيت من مصادر غير معروفة").

ملاحظات:
- التطبيق محتاج إنترنت أول مرة عشان يحمّل مكتبة الـ3D (Three.js) من cdnjs.
- الأيقونة هنا افتراضية (مفيش أيقونة مخصصة).
