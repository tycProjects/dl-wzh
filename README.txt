BUILD APK TRÊN ĐIỆN THOẠI (không cần máy tính):
1. Tạo tài khoản github.com, tạo repository mới.
2. Upload TOÀN BỘ file/thư mục trong zip này lên repo (nhớ cả thư mục .github).
3. Vào tab Actions -> "Build APK" -> chờ chạy xong (~3-5 phút).
4. Mở lần chạy đó -> mục Artifacts -> tải LSUPRA-FPS-Meter-APK -> giải nén -> cài app-debug.apk.

CẬP NHẬT: giao diện đơn giản hơn (mục NÂNG CAO gập sẵn); thêm nút KHÓA CỨNG VỊ TRÍ trong mục VỊ TRÍ.
Bản mới: bỏ màn hình chào, FPS mặc định nằm sát góc dưới-trái, giao diện gọn hơn.
