MONSTERS FC - PROJETO ANDROID

Este pacote contém o projeto-fonte de um aplicativo Android nativo (WebView offline) do Monsters FC.
O escudo enviado foi usado como ícone do app e dentro do aplicativo.

COMO GERAR O APK
1. Extraia a pasta MonstersFC.zip.
2. Abra a pasta MonstersFC no Android Studio.
3. Aguarde o Android Studio sincronizar o projeto Gradle.
4. Se pedir, instale/seleciona Android SDK 35 e JDK 17 ou superior.
5. Vá em Build > Build Bundle(s) / APK(s) > Build APK(s).
6. O APK de teste será gerado em app/build/outputs/apk/debug/app-debug.apk.

CONTEÚDO
- Início e identidade do clube
- Elenco titular 4-3-3 e banco
- Sala de troféus
- Resultado Monsters FC 67 x 1 Remo
- Classificação parcial com o clube em 3º com 67 pontos
- Uniforme e cores

Observação: os títulos e estatísticas são os dados fictícios do universo do Monsters FC, conforme informados na conversa. Este ambiente não tem Android SDK/Gradle instalados para compilar e assinar um APK diretamente; por isso o arquivo entregue é o projeto Android pronto para abrir e gerar o APK no Android Studio.
