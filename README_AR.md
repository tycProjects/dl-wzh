# FILE MAX — مدير ملفات أندرويد

مشروع Android Studio بلغة Kotlin وواجهة Jetpack Compose، بواجهة عربية واتجاه RTL وألوان فاتحة مع لمسات ذهبية.

## المتطلبات
- Android Studio حديث.
- JDK 17.
- Android SDK Platform 35.
- اتصال إنترنت في أول مزامنة Gradle لتنزيل الاعتماديات.

## فتح المشروع
1. فك ضغط `FILE_MAX_Android.zip`.
2. افتح Android Studio ثم اختر **Open**.
3. اختر مجلد `FILE_MAX_Android` الذي يحتوي على `settings.gradle.kts`.
4. وافق على مزامنة Gradle وانتظر تنزيل المكتبات.
5. اختر هاتفاً متصلاً مع تفعيل USB debugging أو محاكي Android.
6. اضغط **Run**.

## إنشاء APK
من Android Studio:
`Build > Build Bundle(s) / APK(s) > Build APK(s)`

بعد نجاح البناء ستجد الملف عادةً في:
`app/build/outputs/apk/debug/app-debug.apk`

يمكن أيضاً البناء من الطرفية بعد تثبيت Gradle وAndroid SDK:
- Windows: `gradlew.bat assembleDebug`
- Linux/macOS: `./gradlew assembleDebug`

> لا يتضمن الأرشيف Gradle Wrapper؛ افتح المشروع بواسطة Android Studio ليستخدم Gradle المتوافق أو أضف Wrapper من بيئة التطوير لديك.

## الوظائف في هذه النسخة المحسّنة
- اختيار مجلد من الهاتف أو بطاقة SD باستخدام Android Storage Access Framework.
- حفظ اختيار مجلد التخزين واستعادته عند فتح التطبيق لاحقاً.
- تصفح المجلدات والتنقل للأعلى بزر التطبيق أو زر الرجوع.
- بحث فوري بالاسم داخل المجلد المفتوح.
- إظهار وإخفاء الملفات المخفية التي يبدأ اسمها بنقطة.
- ترتيب العناصر حسب الاسم أو تاريخ التعديل أو الحجم، مع إظهار المجلدات أولاً.
- إنشاء مجلد جديد مع التحقق من الاسم وعدم تكرار الاسم.
- إعادة تسمية الملفات والمجلدات.
- حذف بعد نافذة تأكيد.
- نسخ الملفات والمجلدات مع اختيار اسم غير متكرر تلقائياً.
- فتح الملفات بواسطة تطبيق مناسب مثبت على الجهاز.
- مشاركة الملفات عبر قائمة مشاركة أندرويد.
- إنشاء أرشيف ZIP للملفات والمجلدات.
- فك ضغط ZIP مع رفض مسارات الخروج من مجلد الوجهة، وتحديد عدد العناصر والحجم لتقليل مخاطر الأرشيفات الضارة.
- تنفيذ عمليات القراءة والنسخ والضغط وفك الضغط في خلفية التطبيق، مع عرض حالة العملية.
- واجهة عربية RTL ورسائل خطأ مفهومة.

## حدود أندرويد والصلاحيات
يستخدم التطبيق نافذة اختيار المجلد الرسمية (SAF)، ولا يطلب صلاحية شاملة للوصول إلى كل الملفات. يستطيع التطبيق العمل داخل المجلدات التي يختارها المستخدم ويمنحه النظام صلاحية الوصول إليها. قد يمنع أندرويد الوصول إلى مجلدات محمية مثل `Android/data` و`Android/obb` أو بعض مواقع بطاقة SD حسب إصدار النظام والشركة المصنّعة.

## ما لا تتضمنه النسخة بعد
- دعم صيغ 7Z وRAR وTAR.
- عرض نماذج GLB/GLTF/OBJ ثلاثية الأبعاد.
- مشغل وسائط مدمج أو عارض PDF مدمج؛ فتح الملفات يتم عبر التطبيقات المثبتة.
- نقل بين مزودي تخزين مختلفين أو مدير مهام نقل متعدد.
- ضغط مشفر بكلمة مرور.
- اختيار متعدد للعناصر، سلة محذوفات، مزامنة سحابية، أو مدير صلاحيات متقدم.

## التحقق والاختبار
لم يتم تنفيذ بناء Gradle أو اختبار على جهاز حقيقي في بيئة إعداد هذا الأرشيف لعدم توفر Android SDK وGradle هنا. قبل الاعتماد أو النشر:
1. نفّذ Gradle Sync.
2. ابنِ نسخة Debug.
3. اختبر اختيار مجلد داخلي وبطاقة SD إن توفرت.
4. اختبر إنشاء مجلد، إعادة التسمية، النسخ، الحذف، فتح ملف ومشاركته.
5. اختبر ضغط وفك ضغط ZIP يحوي ملفات ومجلدات وأسماء عربية.
6. اختبر الأرشيفات الكبيرة والملفات التي لا يملك التطبيق إذن الوصول إليها.
7. راجع سجل Logcat قبل النشر.
