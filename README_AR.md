# همس Hams — إصدار الواجهة Native 1.1

مشروع Android Studio بواجهة عربية RTL مبنية بـ **Kotlin + XML**، وليس WebView. هذا تحديث تجميلي ووظيفي للمشروع الأول: توحيد المسافات والبطاقات، تحسين التدرجات والحواف، إضافة مظهر فاتح، ألوان قابلة للتبديل، وحفظ محلي أفضل.

## التشغيل
1. فك ضغط `HamsAndroid.zip`.
2. افتح مجلد `HamsAndroid` في Android Studio.
3. انتظر اكتمال Gradle Sync.
4. شغّل على هاتف Android أو محاكي.
5. لبناء APK من Android Studio: **Build → Build APK(s)**.

## ما أُضيف في هذا التحديث
- واجهة أكثر اتساقًا: بطاقة ترحيب، عناوين أقسام، بطاقات موحدة، مسافات وحواف محسّنة، وتباين أفضل.
- تبويبات المحادثات والحالات والمكالمات والإعدادات بتحديد بصري واضح.
- بحث في أسماء جهات الاتصال ونصوص المعاينة.
- إضافة جهات اتصال ومحادثات تجريبية.
- شاشة محادثة محسنة، فقاعات رسائل، إرسال محلي وحفظ الرسائل بعد إغلاق التطبيق.
- إنشاء حالة نصية وحفظها محليًا.
- تبديل المظهر الداكن/الفاتح، واختيار لون بنفسجي/تركواز/وردي/أزرق، وتغيير حجم النص.
- عرض نسخة احتياطية JSON ونسخها إلى الحافظة.
- تأكيد قبل مسح البيانات وإرجاع جهات الاتصال التجريبية.
- تحسين شريط الحالة والتنقل ليتناسقا مع المظهر.

## حدود النسخة الحالية
- هذه نسخة تجريبية محلية، وليست خدمة مراسلة متصلة بالإنترنت.
- لا يوجد تسجيل دخول حقيقي، أو إرسال بين أجهزة، أو تشفير طرفي، أو مكالمات صوتية/مرئية حقيقية.
- الكاميرا والفلاتر والوسائط المتقدمة والمزامنة والخادم لم تُنفّذ بعد.
- لم يتم إنشاء APK مُجمّع في بيئة العمل الحالية؛ الملف المرفق مشروع Android Studio يحتاج إلى Gradle Sync ثم Build APK(s).
- لم تُثبت المطابقة البصرية الكاملة لكل شاشة في ملف HTML الأصلي؛ هذا تحديث كبير للواجهة الأصلية Native، ويمكن مواصلة تحويل بقية التفاصيل على مراحل.
