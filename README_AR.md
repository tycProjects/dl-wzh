# مشروع تطبيق وقف — Android

هذا مشروع مصدر أولي كامل قابل للتعديل، يستخدم واجهة HTML/CSS/JavaScript داخل Android WebView، ويتصل بخادم الذكاء الاصطناعي الذي أعددته.

## ما الذي يحتويه؟
- واجهة عربية RTL بتصميم زجاجي داكن وخلفيات متحركة.
- مساعد ذكاء اصطناعي متصل بـ `https://waqf-ai.bu5arius4.workers.dev/chat`.
- خطة يومية بثلاثة تمارين قابلة للتأشير.
- متابعة اختيارية لتاريخ البداية والهدف، محفوظة محليًا.
- مكتبة توعوية ومصادر عامة وروابطها.
- إعدادات خصوصية ومسح البيانات المحلية.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `waqf-android` كمشروع Android في Android Studio متوافق مع Android Gradle Plugin 8.7.3 وJDK 17.
3. انتظر مزامنة Gradle ثم ابنِ APK من قائمة Build.

قد لا تدعم بعض إصدارات AIDE القديمة إعداد Gradle الحديث؛ إذا لم يفتح المشروع فيها، استخدم إصدار Android Studio متوافقًا أو أخبرني برسالة الخطأ المحددة لنجهز صيغة تناسب بيئة البناء لديك.

## ملاحظات
- هذا مشروع مصدر، وليس APK مبنيًا.
- يلزم اتصال إنترنت حتى يعمل المساعد الذكي. الواجهة والخطة اليومية تعملان دون اتصال، لكن الروابط الخارجية والمساعد يتطلبان الإنترنت.
- لا يحتوي التطبيق على مفتاح سري؛ يتصل بعنوان Worker العام.
- البيانات المحلية محفوظة على الجهاز. الرسائل المرسلة للمساعد تمر عبر Worker ونموذج الذكاء الاصطناعي.
- محتوى التوعية عام وليس تشخيصًا أو بديلًا عن مختص صحي.
