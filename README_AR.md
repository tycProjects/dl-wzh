# مشروع همس Hams — Android Native (XML + Kotlin)

هذه نسخة أولية من تحويل واجهة `hams.html` إلى مشروع Android Studio أصلي. الواجهة الرئيسية والمحادثات التجريبية مبنية بـ XML وKotlin، وليست WebView.

## فتح المشروع
1. فك ضغط `HamsAndroid.zip`.
2. افتح مجلد `HamsAndroid` من Android Studio.
3. انتظر Gradle Sync، ثم شغّل التطبيق على هاتف Android أو محاكي.
4. لإنشاء APK: **Build > Build APK(s)**.

## الموجود حاليًا
- واجهة عربية RTL بألوان همس البنفسجية والزجاجية.
- تبويبات المحادثات والحالات والمكالمات والإعدادات.
- البحث في المحادثات وإضافة جهة اتصال تجريبية.
- محادثة محلية وإرسال رسائل تجريبية.
- حفظ جهات الاتصال والرسائل محليًا باستخدام SharedPreferences.
- نشر حالة نصية محلية.

## مهم
هذا ليس تطبيق مراسلة متصلًا بالإنترنت بعد، ولا يتضمن تسجيل دخول حقيقيًا أو مكالمات فعلية أو كاميرا/فلاتر أصلية. لم يُبنَ APK جاهز داخل هذه البيئة؛ المرفق هو مشروع Android Studio قابل للفتح والبناء. هذه المرحلة تنقل البنية الأساسية، ولا تدّعي مطابقة كل تفاصيل HTML الأصلية بعد. يمكن استكمال بقية الشاشات والوظائف تدريجيًا مع الحفاظ على XML/Kotlin.
