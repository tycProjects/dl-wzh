مشروع AURORA — تطبيق ترحيبي عربي بلغة Java لأندرويد
===================================================

محتويات المشروع:
- مشروع Android Gradle أصلي بلغة Java.
- واجهة عربية داكنة بتصميم حديث.
- بطاقات تفاعلية وأزرار تعرض رسائل تجريبية.
- لا يحتاج إلى صلاحيات خاصة أو اتصال بالإنترنت.

مهم:
هذا ZIP هو مشروع Android Gradle كامل، وليس APK جاهزاً.
قد لا يقبل WZH 2 APK هذا النوع من ZIP؛ فالقبول يعتمد على أنواع المشاريع التي يدعمها التطبيق.
إذا رفضه WZH، يمكن استخدام بيئة بناء أندرويد متوافقة على الهاتف أو تعديل المشروع إلى صيغة يدعمها.
