AURORA ROOT — مشروع أندرويد أصلي بلغة Java
=========================================

ما الذي يفعله؟
- يطلب صلاحية su عند فتح التطبيق لأول مرة، عبر Magisk/Superuser إن كانت البيئة تدعم ذلك.
- يفحص هل الأمر id يعمل بهوية uid=0.
- يعرض معلومات قراءة فقط: إصدار أندرويد، الشركة المصنّعة، طراز الجهاز، SDK وهوية العملية.
- لا ينفذ أوامر حذف أو تعديل للنظام.

طريقة الاستخدام:
1. استورد ملف ZIP في أداة بناء تدعم مشروع Android Gradle أصليًا.
2. إذا كان WZH 2 APK يقبل ZIP لمشاريع HTML فقط، فلن يبني هذا المشروع مباشرة.
3. عند البناء، وقّع APK وثبّته على جهازك.
4. افتح التطبيق، ثم وافق على طلب الروت في Magisk إن ظهر.
5. جرّب زر "عرض معلومات النظام".

ملاحظات:
- هذا ZIP هو مصدر مشروع، وليس APK مبنيًا.
- لا يمكن ضمان أن WZH 2 APK يدعم مشاريع Gradle/Java أصلية؛ يعتمد ذلك على وظيفة استيراد ZIP فيه.
- طلب su لا يضمن ظهور نافذة Magisk إذا لم يكن Magisk مثبتًا/مفعّلًا أو إذا منعت بيئة التطبيق ذلك.
- استخدم صلاحيات الروت بحذر.
