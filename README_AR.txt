AURORA TITAN — مشروع أندرويد Java مع أدوات روت
================================================

الميزات:
- فحص صلاحيات su عند بدء التشغيل.
- تغيير سرعات رسوم الحركة الثلاث:
  window_animation_scale
  transition_animation_scale
  animator_duration_scale
- قراءة معلومات الجهاز والنظام والنواة ووقت التشغيل.
- فتح صفحات إعدادات أندرويد وخيارات المطور.
- إنشاء تقرير نصي في مجلد ملفات التطبيق الخاص.
- واجهة عربية RTL مع ثيم داكن.

مهم:
- ZIP هو مشروع Android Gradle أصلي وليس APK مبنيًا.
- دعم WZH 2 APK لمشاريع Java/Gradle غير مؤكد؛ إذا كان يدعم مشاريع HTML فقط، لن يستطيع بناء هذا المشروع مباشرة.
- تغييرات الحركة تُطبّق عبر Magisk/su وتكون قابلة للعكس من داخل التطبيق بإرجاع القيم إلى 1×.
- أزرار الإعدادات تفتح صفحات النظام ولا تتجاوز القيود التي يفرضها Android أو MIUI.
- تقرير النظام يُحفظ داخل مجلد التطبيق الخاص، ولا يُكتب إلى ملفات النظام.
- التطبيق لا يحذف ملفات، ولا يوقف خدمات النظام، ولا يعدّل ملفات النظام تلقائيًا.
- استخدام الروت مسؤولية المستخدم. لا تمنح صلاحيات لتطبيقات لا تثق بها.
