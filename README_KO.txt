Infinite Stairs AUTO Vision 0.2 — 실험용 네이티브 Android 프로젝트

이 버전은 WZH 2의 index.html 빌더용이 아닙니다. AndroidIDE/Android Studio처럼 Gradle 네이티브 프로젝트를 빌드하는 도구가 필요합니다.

화면 인식:
- Android MediaProjection으로 사용자가 승인한 화면 프레임을 가져옵니다.
- 제공된 할로윈 플레이 영상에서 보이는 주황색 계단 타일 색상 신호를 좌/우 영역에서 세어 방향을 추정합니다.
- 이것은 학습된 AI가 아니라 단순 색상 기반 컴퓨터 비전 실험입니다. 장식/이펙트에 오인할 수 있고 정확성이 검증되지 않았습니다.
- 다른 스킨에서는 잘 작동하지 않을 수 있습니다.

조작:
- 접근성 서비스가 켜져 있어야 입력이 가능합니다.
- 인식 결과가 LEFT면 좌측 회전 버튼 후 올라가기 버튼, RIGHT면 올라가기 버튼을 누르도록 시도합니다.
- HOLD는 신뢰도가 낮아 입력하지 않습니다.
- 게임 화면 배치/해상도에 따라 좌표 조정이 필요합니다.

빌드:
1. AndroidIDE에서 이 폴더를 엽니다.
2. Gradle Sync 후 APK 빌드.
3. 앱 실행 → 접근성 서비스 설정에서 Infinite Stairs AUTO 입력 서비스 활성화.
4. 앱으로 돌아와 화면 인식 권한 허용 및 시작.
5. 게임으로 이동해 짧게 테스트. 이상 입력이 있으면 즉시 앱에서 정지.

중요:
- APK 빌드 및 실기기 동작 검증은 아직 되지 않았습니다.
- 무한 등반을 보장하지 않습니다. 우선 방향 인식 결과와 터치 좌표를 실제 화면에 맞게 조정해야 합니다.
- 화면 캡처와 접근성 권한은 Android가 사용자에게 직접 동의를 요청합니다.
