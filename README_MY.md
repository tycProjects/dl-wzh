# Kyaw Gyi Scanner — Android Project Starter

ဒီ ZIP သည် Android Studio ဖြင့် ဖွင့်ပြီး build စမ်းသပ်နိုင်ရန် ရည်ရွယ်ထားသော Kotlin/Jetpack Compose starter project ဖြစ်သည်။

## အရေးကြီး
- ဤ project သည် UI starter/demo ဖြစ်ပြီး Starlink/Ruijie portal အားလုံးကို detect လုပ်နိုင်သည်ဟု အာမမခံပါ။
- Voucher code guessing, credential brute-force, rate-limit bypass သို့မဟုတ် unauthorized login မပါဝင်ပါ။
- ကိုယ်ပိုင် သို့မဟုတ် စမ်းသပ်ခွင့်ရှိသော network တွင်သာ security testing လုပ်ပါ။

## Build လုပ်နည်း
1. ZIP ကို extract လုပ်ပါ။
2. Android Studio ဖွင့်ပြီး `KyawGyiScanner` folder ကို Open လုပ်ပါ။
3. Gradle sync ပြီးစီးသည်အထိ စောင့်ပါ။ Internet လိုနိုင်သည်။
4. JDK 17 ကို ရွေးထားကြောင်း စစ်ပါ။
5. Android device သို့မဟုတ် emulator ကို ချိတ်ပြီး Run ကိုနှိပ်ပါ။

## မှတ်ချက်
ဤ environment မှာ Android Gradle build ကို run/verify မလုပ်ထားပါ။ ထို့ကြောင့် build အောင်မြင်ကြောင်း အတည်ပြုထားခြင်း မဟုတ်ပါ။
