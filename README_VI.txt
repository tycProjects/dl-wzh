CÁCH BUILD APK TRÊN ĐIỆN THOẠI

1. Cài AndroidIDE (hoặc AIDE) trên điện thoại.
2. Giải nén project này vào bộ nhớ máy.
3. Mở thư mục project bằng AndroidIDE.
4. Chờ Gradle sync. Nếu hỏi Gradle/SDK, chọn cài Android SDK 35 và build tools tương ứng.
5. Chọn Build > Assemble Debug (hoặc Run).
6. APK nằm tại: app/build/outputs/apk/debug/app-debug.apk
7. Cài APK.
8. Mở launcher có hỗ trợ icon pack và chọn “盛夏黑卷 Icon Pack”.

Lưu ý: Moto Launcher trên một số phiên bản không cho áp icon pack bên thứ ba. Khi đó dùng launcher hỗ trợ icon pack.
