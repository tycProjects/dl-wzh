# Reference notes — Android Island 1.4.2

The following public repositories were reviewed for architecture and interaction patterns:

- EvanKoe / Expressive Cutout: https://github.com/EvanKoe/expressive-cutout
- Arnav-Dugad / dynamic-island-android: https://github.com/Arnav-Dugad/dynamic-island-android
- bughunter11 / Islandify: https://github.com/bughunter11/Islandify
- POX-project / disland: https://github.com/POX-project/disland

This project uses those repositories as design/engineering references only. No repository source files were copied into Android Island. The implementation remains based on this project's existing Kotlin/Jetpack Compose architecture.
