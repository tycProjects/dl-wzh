# Android Island 1.14.16 — Taller AI Panel

- Expanded the assistant panel to use 94% of the usable screen height, excluding status/navigation bars and the keyboard.
- Raised the AI-specific overlay cap to 94% of screen height, reserving space for the capsule anchor, configured vertical offset, and bottom safety margin.
- Removed the WhatsApp-stack height cap from AI panels. WhatsApp stacks remain independently bounded and scrollable.
- Kept the chat list as the flexible area; header and action controls remain pinned.
- Version: 1.14.16 (versionCode 143).

Build/device verification still required in the Android build environment.
