# Android Island 1.4.28

- WhatsApp unread indicator remains independently clickable when media is the active compact activity; tapping it opens the WhatsApp stack.
- Tapping the media capsule while media is active opens the media expansion, independently of the WhatsApp stack indicator.
- Compact/non-compact WhatsApp stack cards continue to use the selected compact banner setting and each card opens its originating notification intent.
- Removed duplicate lyric glow intensity control; glow and shine controls remain independent.
- Increased white glyph-shadow blur while keeping lyric glyph fill OLED black.
- Changed banner swipe-up exit to a timed eased transition and removed alpha-modulated offscreen compositing to reduce rectangular fade artifacts.
