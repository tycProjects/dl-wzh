# Android Island 1.4.49

## Tema Dynamic Island
Pengaturan baru: Adaptif, Terang, Gelap, Native Putih, Native Hitam.

Pilihan tersimpan otomatis di DataStore dan diterapkan pada capsule, expanded media, stack WhatsApp, serta banner WhatsApp. Adaptif memilih warna teks berdasarkan kecerahan artwork/avatar. Mode non-adaptif menggunakan permukaan putih atau hitam dan tinta kontras.
