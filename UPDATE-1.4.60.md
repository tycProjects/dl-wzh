# Android Island 1.4.60

## Profil cutout
- Pilihan profil (Otomatis, iPhone, Waterdrop, Kustom) hanya tampil dan hanya berfungsi saat "Mode iPhone Notch" aktif.
- Punch-hole dan notch lebar tidak lagi dipilih manual; keduanya ditentukan otomatis dari deteksi cutout perangkat (Otomatis).

## Izin & Shizuku
- Shizuku dipindah ke bagian "Izin · Akses sistem" dengan status ON/OFF.
- Toggle "Bersihkan ikon status bar" tetap di bagian Sistem, default mati.

## Animasi
- Preset baru "iOS Ringan": pegas kritis (tanpa pantulan), membuka dan menutup dengan kurva seperti iOS. Tanpa blur, tanpa efek kilau.
- Jadi rekomendasi dan juga default pada instalasi baru. "Terapkan rekomendasi" memakai nilai ini.
- Jelly Halus dan Lembut tetap tersedia.

## Demo
Demo sekarang mencakup: pemutar media, media dijeda, WhatsApp satu pesan, WhatsApp grup (tiga pesan), pesan panjang, panggilan masuk, panggilan berlangsung, media + WhatsApp, dan "Hentikan semua demo".

## Catatan
Kode belum dikompilasi di lingkungan ini. Jalankan build debug dan kirim log bila ada error.
