Bài học Lua cơ bản

Chọn một bài để xem ví dụ. Bạn có thể sao chép code sang mục Test code.

1. In chữ ra màn hình

print("Hello world")

print() dùng để hiển thị nội dung.

2. Biến

local ten = "An" local tuoi = 14 print(ten) print(tuoi)

local tạo biến cục bộ. Lua không cần khai báo kiểu dữ liệu.

3. Phép tính

local a = 10 local b = 5 print(a + b) print(a * b)

Toán tử: +, -, *, /, %.

4. Điều kiện

local diem = 8 if diem >= 5 then print("Dat") else print("Chua dat") end

if / else / end dùng để rẽ nhánh.

5. Vòng lặp

for i = 1, 5 do print(i) end

Vòng for lặp từ 1 đến 5.
