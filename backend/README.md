# DroidStore Backend

Серверная часть (API, авторизация, хранение APK, модерация, аудит).
Здесь будет реализация на выбранном стеке (например, Kotlin/Ktor или Node.js).

Обязательные правила:
- все секреты (JWT-ключи, пароли БД, VirusTotal API key) — только в переменных окружения;
- каждое административное действие пишется в `audit_log`;
- галочки верификации выдаются только через панель администратора.
