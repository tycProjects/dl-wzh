03INTERNAL BUILD ENGINE
WEB2APK V4.8 packages your website into a WebView Android app and signs the APK inside this app. Termux, RUN_COMMAND permission and shared-storage access are not used.
04HOW IT WORKS
1. Select an HTML file, website ZIP, or enter an HTTP/HTTPS URL.
2. Set the app name, package ID, version and optional icon.
3. Choose only the website permissions you need.
4. Tap BUILD SIGNED APK. WEB2APK prepares the wrapper, adds your website files and signs the APK on-device.
5. Android Installer opens for your final confirmation.
05ANDROID PERMISSIONS
File and Photo access: Android system picker only; no broad storage permission.
Termux / RUN_COMMAND: not required and not declared.
Usage Access: not required and never requested.
Install unknown apps: allow WEB2APK to open Android's APK installer on Android 8+.
Notifications: optional build-completion alerts.
Camera, Microphone and GPS: included only in the generated website APK when selected, then requested from the user when the website uses them.
06ABOUT WEB2APK V4.8
Internal WebView APK wrapper · Local package customization · Local APK signing · Android API 23+ output runtime · Orientation, fullscreen, cache and navigation controls.

Note: This builds website/WebView APKs from web content. It is not a general compiler for arbitrary Android Java/Kotlin projects. Live URL apps need internet to display the remote site.
