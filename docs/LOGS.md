# Диагностические логи

Откройте вкладку **Логи**:
- **Скопировать** — помещает весь журнал в буфер обмена; затем вставьте его в чат.
- **Отправить** — открывает стандартное меню Android для отправки текста или файла в приложение/мессенджер.
- **Очистить логи** — удаляет текущий и предыдущий файл журнала.

Журнал находится во внутреннем хранилище приложения. Ротация: текущий файл до 512 KiB
и один резервный файл. В журнал попадают только события, которые приложение явно
записывает через AppLogger. Полный `logcat` не собирается автоматически, чтобы не
захватывать лишние персональные данные.

Перед отправкой можно просмотреть последние строки в приложении.
