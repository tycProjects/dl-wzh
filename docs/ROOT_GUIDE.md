# Root guide

Поддерживаемые менеджеры root: Magisk, KernelSU, APatch (при наличии совместимого `su`).
Приложение вызывает `su -c id` при старте и ожидает UID 0. Root не обходится и не
эксплуатируется автоматически. Пользователь должен явно подтвердить запрос в менеджере.

Для восстановления после неудачного системного мода загрузитесь в safe mode/recovery,
отключите или удалите модуль и перезагрузите устройство.
