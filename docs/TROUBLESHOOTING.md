# Устранение неполадок

- Root не обнаружен: откройте Magisk/KernelSU/APatch и выдайте приложению root-доступ.
- Ошибка записи: проверьте наличие `/data/adb/modules` и разрешение на запись.
- SystemUI перезапускается: не применяйте неподтверждённые overlay; удалите модуль из recovery.
- Устройство не Xiaomi: scaffold помечает семейство производителя, но не гарантирует совместимость.
- Gradle sync: используйте JDK 17 и Android SDK Platform 35.
