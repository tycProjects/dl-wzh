# Использование

- «Отступы»: координаты в px для сдвига иконок, spacing/height в dp.
- «Размер»: коэффициенты масштаба 0.70–1.50.
- «Стиль» и «Цвета»: выбор визуальной конфигурации preview.
- «Профили»: ручной выбор пресета.
- «Сохранить и передать модулю»: запись JSON в `/data/adb/modules/hyperstatusbarpro/config.json`.

Preview — симуляция внутри приложения, а не наложение поверх реального status bar.
